# 跨境电商业务规则（留出文档，仅评测时上传）

## 关税与清关
30. 跨境商品需要交关税吗？
跨境电商保税进口商品按跨境电商综合税率征收，税费在下单时一并收取；单笔订单超过 5000 元或年度超过 26000 元的，按一般贸易方式清关。

31. 清关需要提供身份证吗？
需要。下单时须填写订购人与支付人一致的真实姓名与身份证号，系统仅用于海关清关申报，不做其他用途。

32. 清关一般要多久？
保税仓发货的清关通常 1-2 个工作日；直邮清关可能 3-7 个工作日，遇海关查验会延长。

## 海外直邮
33. 海外直邮多久能到？
欧美仓直邮一般 7-15 个工作日到货，日韩仓 3-7 个工作日；节假日与大促期间可能顺延。

34. 跨境商品可以退吗？
跨境商品因涉及清关，仅支持质量问题退货，需在签收后 7 天内申请并提供质量问题凭证；无质量问题的跨境商品不支持无理由退货。

## 保税仓
35. 保税仓商品为什么发货快？
保税仓商品已提前备货至境内保税区，下单完成清关后由保税区直接发货，因此物流时效接近国内配送。
